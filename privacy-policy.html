CF Performance Mirror

Privacy Policy  ·  Chrome Extension

✔  This extension does not collect, store, or transmit any personal data to any server. All processing happens locally in your browser.

1. Overview

CF Performance Mirror ("the Extension") is a Chrome browser extension that displays enhanced performance statistics on Codeforces profile pages. This Privacy Policy explains what data the Extension accesses, how it is used, and your rights as a user.

This policy applies to all users of the Extension and was last updated on April 13, 2026.

2. Data the Extension Accesses

When you visit a Codeforces profile page (e.g. https://codeforces.com/profile/<username>), the Extension reads the following:

  • Codeforces username — extracted directly from the page URL you are already visiting.
  • Submission history — fetched from the public Codeforces API (codeforces.com/api/user.status) using that username.
  • Contest and rating data — fetched from the public Codeforces API (codeforces.com/api/contest.list and codeforces.com/api/user.rating).

All of this data is publicly available on Codeforces and is only retrieved for the purpose of rendering statistics within your browser.

3. How Data Is Used

Data fetched from the Codeforces API is used exclusively to:

  • Calculate and display performance statistics (solve times, failure rates, rating changes) on the profile page you are viewing.
  • Remember your filter and display preferences locally using localStorage in your browser.

The Extension does not use this data for advertising, analytics, profiling, or any purpose other than rendering the on-page display.

4. Data Storage

The Extension stores your UI preferences (selected division, time range, display options) using the browser's localStorage API. This data:

  • Never leaves your device.
  • Is not accessible to any third party.
  • Can be cleared at any time by clearing your browser's site data for codeforces.com.

5. Data Sharing and Third Parties

We do not share any data with third parties. The only external communication made by the Extension is outbound API requests to codeforces.com — the site you are already browsing. No data is sent to the developer or any analytics service.

6. Permissions

The Extension requests the following permissions:

  • Host access to codeforces.com — required to inject the statistics panel into Codeforces profile pages and to make API requests to the Codeforces public API.

No other permissions are requested or used.

7. Children's Privacy

The Extension is not directed at children under the age of 13. We do not knowingly collect any personal information from children. The Extension only accesses publicly available data on Codeforces.

8. Changes to This Policy

If this Privacy Policy is updated, the new version will be published at this URL. Continued use of the Extension after any changes constitutes acceptance of the updated policy.

9. Contact

If you have any questions about this Privacy Policy, please open an issue on the project's GitHub repository or contact the developer through the Chrome Web Store listing.
