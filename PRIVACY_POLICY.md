Privacy Policy for CF Performance Mirror

CF Performance Mirror does not collect, store, transmit, or sell any personal or
private user data.

The extension only accesses publicly available information from Codeforces
profiles and the official Codeforces public API in order to compute and display
contest performance statistics directly on the Codeforces website.

No personally identifiable information (PII) is collected.
No authentication data is accessed.
No data is stored outside the user’s browser.
No tracking, analytics, or advertisements are used.

All processing is done locally in the user’s browser.
